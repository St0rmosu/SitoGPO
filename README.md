# 🌿 RE-LIFE (sitogpo)

[![Next.js](https://img.shields.io/badge/Next.js-000000?style=for-the-badge&logo=nextdotjs&logoColor=white)](https://nextjs.org/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)](https://tailwindcss.com/)
[![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?style=for-the-badge&logo=typescript&logoColor=white)](https://www.typescriptlang.org/)

**RE-LIFE** è una startup innovativa focalizzata sulla sostenibilità e l'upcycling. Questo progetto rappresenta la piattaforma web ufficiale della startup, progettata per facilitare la rigenerazione di mobili e ridurre l'impatto ambientale.

## 🎯 Obiettivi
- **Sostenibilità**: Rigeneriamo mobili usati per risparmiare CO₂ e ridurre gli sprechi.
- **E-commerce**: Una piattaforma moderna per la vendita di pezzi unici rigenerati.
- **Logistica Efficiente**: Sistema integrato per la gestione del recupero e della consegna.

## 🛠️ Tech Stack
- **Frontend**: Next.js 15+, React, Tailwind CSS, Framer Motion.
- **Linguaggio**: TypeScript.
- **Database**: PostgreSQL (Schema disponibile in `SCHEMA.sql`).
- **Deployment**: Ottimizzato per Vercel.

## 🚀 Sviluppo Locale
1. Installa le dipendenze:
   ```bash
   npm install
   ```
2. Avvia il server di sviluppo:
   ```bash
   npm run dev
   ```
3. Visita `http://localhost:3000`.
